# LearningParadise 开发规范与智能体协作指南

如果您是接手本项目的 AI 智能体（或新的会话流），请在进行任何界面开发或功能修改前，务必仔细阅读并严格遵循以下 **4 大核心约定**。这些规范是多轮验证后确立的基石，能够确保项目的纯粹性、一致性与适老化体验。

## 1. 核心设计语言：100% 拟真 Minecraft 风格
- **基础面板 (GUI Panel)**：严禁使用“毛玻璃 (Glassmorphism)”、“半透明”等现代 Web 风格。必须使用系统预设的 `.mc-panel` 样式（深灰色 `#3C3C3C` 实心底，2px 纯黑外边框，辅以左上亮 `#8B8B8B`、右下暗 `#1A1A1A` 的内部凹凸立体阴影）。
- **字体与文本**：全站必须统一使用 `font-mc` (`Press Start 2P` 像素字体)。所有大标题文字必须附带沉重的黑色像素阴影（例如 `style={{ textShadow: "2px 2px 0 #000" }}`）。
- **背景处理**：全局固定一张高清 Minecraft 官方壁纸，并在 `layout.tsx` 顶层统一施加一层恒定的 `backdrop-blur-sm backdrop-saturate-50 bg-black/40` 特效，以保证任何前台背景下 UI 面板的极高可读性。
- **适老化大字号**：考虑到系统的主要受众是儿童，需绝对避免使用 `text-xs` 及更小的极小字号，排版基准字号应为 `text-base` 到 `text-lg`。

## 2. 资产与素材库标准 (Asset Standards)
- **禁止自行生成图形**：涉及游戏内物品、武器、防具、食物、角色头像等素材，**严禁 AI 擅自用代码生成 SVG 拼凑图（如所谓的纸娃娃系统）或使用无来源的占位图**。
- **素材来源唯一**：所有的装备图标和声音素材都必须从官方中文维基 (https://minecraft.wiki) 抓取。
- **文件规范**：装备图标必须提取高分辨率大图（如 160x160 尺寸），并持久化存放到 `public/icons` 目录下；前端渲染必须挂载 `.pixel-image` CSS 类以保证 `image-rendering: pixelated` 的像素锐利度。
- **默认占位**：当装备栏没有穿戴具体的装备物品时，必须展示使用 SVG 勾勒的同等比例的像素线稿（如空头盔、空剑的虚线轮廓），绝对不允许简单留白。

## 3. 音效集成机制
- 采用 `Howler.js` 构建声音系统。
- **无痕挂载**：禁止在每一个零散的按钮中手写单独的音频触发逻辑。必须利用项目中已封装好的顶层 `SoundContext` 事件委托机制，它会自动捕获全局的按钮（含有 `button` 标签）的点击动作并播放 `Click.ogg`。
- **特殊事件**：当触发重要业务节点（例如：完成口算考试后产生 `leveledUp` 经验升级行为时），需要显式引入 Context 并调用 `playLevelUp()`。

## 4. 前端架构与路由组织
- **Next.js App Router**：保持基于目录的现代路由风格，保证端到端类型安全。
- **科目拓展性**：不允许将具体的学习科目堆砌在根级或简单的短路径下。口算模块被固定在 `/practice/math`，以确保未来可横向、平滑地扩展 `/practice/english`、`/practice/logic` 等新学习科目。
- **管理后台隔离**：通过 `/admin` 独立路径访问，需先过一遍硬编码密码系统（当前验证密码为 `admin123`），拦截闲杂人员。管理员接口（如 `/api/admin/stats`）要求必须验证 Authorization 头。
